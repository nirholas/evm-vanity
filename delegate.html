✦ Delegate a grind, keep the key

Every paid vanity grinder sees the key it sells you. Split-key grinding removes the objection with arithmetic instead of a promise: your browser picks a secret scalar k1 and publishes only the point P1 = k1·G. The remote grinder searches offsets k2 until the address of P1 + k2·G matches your pattern, then hands back k2. It never sees k1, so it cannot compute the private key, and you combine k = (k1 + k2) mod n here, in this tab.

On secp256k1 there is no catch: the combined scalar is an ordinary 32-byte private key. It imports into MetaMask, ethers, viem, Rabby or a keystore file exactly like a key you generated yourself. (The Ed25519 version of this trick, on Solana, produces an expanded key that seed-only wallets reject. Not here.)
